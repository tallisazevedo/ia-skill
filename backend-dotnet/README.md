# Backend .NET Skills

Pasta do roteador e das referências compartilhadas da família.

A documentação completa — instalação, as oito skills, os fluxos por tipo de trabalho, os padrões
e as armadilhas — está no [README da raiz](../README.md).

- [`SKILL.md`](SKILL.md) — o roteador. Digite `backend-dotnet` para escolher o fluxo.
- [`references/`](references) — fonte única de verdade das regras compartilhadas, exposta pela
  skill `backend-dotnet-padroes`.

Quando uma regra corporativa mudar, atualize a referência correspondente — não a skill.
